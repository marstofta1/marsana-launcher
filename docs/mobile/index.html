Android kurulum

  1. APK'yı indir — yukarıdaki düğmeye bas.
  2. Bilinmeyen kaynaklara izin ver — tarayıcı veya Dosyalar uygulamasına kurulum izni ver.
  3. APK'yı aç ve kur — indirilen dosyaya dokun, Kur de.
  4. Marsana Launcher'ı aç — OYNA ile Minecraft Bedrock açılır.

iOS kurulum

  1. IPA'yı indir — bilgisayara veya iPhone'a aktar.
  2. AltStore / Sideloadly kur — ücretsiz Apple ID ile imzalama yapılır (7 günde bir yenileme gerekebilir).
  3. IPA'yı yükle — araca sürükle bırak veya Install de.
  4. Güven — Ayarlar → Genel → VPN ve Cihaz Yönetimi'nden geliştiriciye güven.

Uygulama henüz App Store / Play Store'da değil; paketler GitHub Releases üzerinden dağıtılır. Kaynak kodu GitHub'da açık.
