v0.1.24 · iOS 14+ · imzalama zorunlu

Android kurulum

  1. APK'yı indir — yukarıdaki düğmeye bas.
  2. Bilinmeyen kaynaklara izin ver — tarayıcı veya Dosyalar uygulamasına kurulum izni ver.
  3. APK'yı aç ve kur — indirilen dosyaya dokun, Kur de.
  4. Marsana Launcher'ı aç — OYNA ile Minecraft Bedrock açılır.

iOS kurulum (Sideloadly — önerilen)

  1. IPA'yı bilgisayara indir — yukarıdaki IPA İNDİR düğmesi (v0.1.24).
  2. iPhone'u USB ile bağla — Bu Bilgisayara Güven de.
  3. Sideloadly kur — Windows veya Mac.
  4. IPA'yı Sideloadly'ye sürükle, Apple ID gir, Start de.
  5. Telefonda: Ayarlar → Genel → VPN ve Cihaz Yönetimi → Apple ID → Güven.
  6. Ana ekrandan Marsana Launcher'ı aç.

iOS açılmıyorsa

  • Eski kurulumu sil — ana ekranda uzun bas → Uygulamayı Kaldır.
  • v0.1.24 IPA kullan (eski 0.1.23 imzasız kalıyordu, hemen kapanıyordu).
  • IPA'yı yalnızca Dosyalar'dan açma — Sideloadly/AltStore şart.
  • Sideloadly'de cihaz görünmüyorsa kablo/sürücü kontrol et; iTunes veya Apple cihaz paketi yüklü olsun.
  • İkon görünüp uygulama hemen kapanıyorsa Güven adımını atlamış olabilirsin.

Uygulama App Store / Play Store'da değil. Ücretsiz Apple ID ile imza ~7 gün sürer; sonra Sideloadly ile tekrar yükle. Kaynak kodu GitHub'da açık.
