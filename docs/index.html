İndir

Marsana Launcher'ın en güncel sürümünü aşağıdan işletim sistemine uygun paketi indirerek kurabilirsin. Her platform için sürümünüze veya dağıtımınıza uygun paketi seçin.

Windows (64 bit)

Windows 11, 10, 8.1 veya 7 için ayrı indirme bağlantıları. Kurucu aynı sürümdür; Windows 10 ve 11 tam desteklenir. Windows 7/8.1'de çalışmayabilir — mümkünse Win 10+ önerilir. (Resmi Windows 9 sürümü yayımlanmamıştır.)

macOS

macOS 15 Sequoia, 14 Sonoma, 13 Ventura, 12 Monterey veya 11 Big Sur için indirme kartları. Paket Intel + Apple Silicon universal .dmg dosyasıdır.

Linux

Ubuntu, Linux Mint, Debian, Fedora, Manjaro, MX Linux, Solus ve Elementary OS için indirme kartları. Hepsi aynı x86_64 AppImage dosyasıdır; dağıtımınıza uygun kartı seçin.

Android

Android 16, 15, 14 veya 13 için indirme kartları. Hepsi aynı APK dosyasıdır; Bedrock (Minecraft PE) başlatıcısıdır. Sürümünüze uygun kartı seçin.

iOS

iOS 18, 17, 16, 15 veya 14 için indirme kartları. Hepsi aynı IPA dosyasıdır; Sideloadly veya AltStore ile kurulur. Sürümünüze uygun kartı seçin.

Windows kurucuları bu siteden doğrudan indirilir (sürümünüze uygun kartı seçin). macOS paketleri GitHub Releases üzerinden sunulur (sürümünüze uygun kartı seçin). Detayli mobil kurulum icin mobil sayfaya bak; macOS'ta ilk açılışta Gatekeeper uyarısı çıkarsa Sistem Ayarları → Gizlilik ve Güvenlik üzerinden izin ver. Linux'ta gerekirse chmod +x Marsana*.AppImage ile çalıştırma izni ver. Windows kurucusu henüz dijital olarak imzalı değil; SmartScreen ilk açılışta "Daha fazla bilgi → Yine de çalıştır" demen gerekebilir.

Marsana Launcher Nedir?

Marsana Launcher, Mojang'ın resmi Minecraft Java Edition oyununu başlatmak için yazılmış, Electron tabanlı bir masaüstü uygulamasıdır. Resmi Minecraft Launcher'a kıyasla Türkçe arayüzü, hazır mod yığınları ve önerilen sunucu listesi ile farklılaşır. Oyunu içermez; sadece çalıştırır.

Microsoft girişi + offline mod

Microsoft hesabınla giriş yap (önerilen) veya çevrimdışı modda yerel olarak oyna.

Tüm sürümler

Release, snapshot, eski sürümler (1.x.y), hatta 1.0 öncesi alpha/beta sürümleri.

Mod yükleyicileri

Fabric · Fabric (Beta) · Forge · NeoForge · Quilt · Legacy Fabric · LiteLoader · NilLoader · Ornithe · Rift — otomatik kurulur.

Hazır mod yığınları

Tek tıkla Iris + Sodium + Complementary Reimagined shader; ya da Continuity CTM.

OptiFine entegrasyonu

Forge + OptiFine veya Fabric için OptiFine paketi otomatik indirilir ve kurulur.

Java otomatik yönetilir

Sürüm uyumu (Java 8, 17, 21) Mojang'ın resmi runtime'larıyla otomatik çözülür.

Önerilen sunucular

Topluluğun aktif Türkçe sunucuları arayüzde önceden listelidir.

Hafıza ayarı

RAM tahsisini kaydırıcıyla ayarla; sistemin üst sınırı otomatik hesaplanır.

⚠ Premium Hesap Zorunlu

Marsana Launcher, Minecraft oyununu satmaz — sadece başlatır. Oynayabilmek için Microsoft hesabında Minecraft Java Edition lisansının (yaygın adıyla "premium hesap") tanımlı olması zorunludur. Bu lisans olmadan oyun sunucularına bağlanamazsın ve tek kişilik modda bile resmi giriş başarısız olur.

Premium hesap nasıl alınır?

  • minecraft.net adresinden Microsoft hesabınla tek seferlik satın alma yap (Java + Bedrock paketi yaklaşık 27 €).
  • Aboneliksizdir; bir kez satın alındığında o Microsoft hesabına süresiz bağlıdır.
  • Satın aldıktan sonra Marsana Launcher'da "Microsoft ile Giriş Yap"a tıkla; tarayıcıda hesabını onayla, geri dön.

Korsan / crack hesap çalışır mı?

Hayır. Marsana yalnızca resmi Microsoft kimlik doğrulama akışını kullanır (msmc + Mojang token değişimi). "Cracked" hesaplarla giriş desteklenmez; oyun çevrimiçi sunuculara bağlanamaz. Çevrimdışı mod yerel oyun için tek başına yeterlidir ama Mojang oturum doğrulaması gerektirmez — yine de yasal kullanım için premium hesap önerilir.

Kurulum ve İlk Adımlar

  1. İndir. Yukarıdaki "İndir" bölümünden işletim sistemine uygun paketi GitHub Releases'tan indir.
  2. Kur. Windows'ta .exe kurucusunu çift tıkla; macOS'ta .dmg'yi açıp uygulamayı Applications klasörüne sürükle (ilk açılışta Gatekeeper uyarısı normal — aşağıdaki SSS'ye bak); Linux'ta .AppImage dosyasına çalıştırma izni verip çift tıkla (chmod +x Marsana*.AppImage).
  3. Giriş yap. İlk açılışta "Microsoft ile Giriş Yap" butonuna bas; tarayıcı açılır, hesabını onayla, geri dön. Token'ın yerel olarak güvenli şekilde saklanır.
  4. Sürüm ve yükleyici seç. Sürüm açılır menüsünden istediğin Minecraft sürümünü, mod paneli'nden de yükleyiciyi seç (varsayılan: Vanilla).
  5. Oyna. "OYNA" butonuna bas; Java ve gerekli dosyalar otomatik indirilir, ilk açılışta birkaç dakika sürer; sonraki açılışlar saniyeler içinde başlar.

Sistem Gereksinimleri

İşletim Sistemi

Windows 11/10 (önerilen, 64 bit), Windows 8.1/7 (sınırlı), macOS 11+, popüler Linux dağıtımları

İşlemci

Modern x86_64 işlemci (Intel/AMD); macOS'ta Apple Silicon (M1/M2/M3) doğal olarak desteklenir.

Bellek (RAM)

Minimum 4 GB; mod ve shader için 8 GB önerilir, ağır mod paketlerinde 12+ GB.

Disk Alanı

Boş kurulum ~500 MB; sürüm dosyaları ve modlarla birlikte 5–20 GB'a çıkabilir.

Java

Kendin kurmana gerek yok. Marsana, Mojang'ın resmi Java runtime'larını gerektiğinde otomatik indirir.

Ağ

İlk açılışta sürüm indirme için stabil internet; sonradan offline modda oynanabilir.

Sık Sorulan Sorular

Hesabım yok, nasıl alırım?

minecraft.net'ten Microsoft hesabınla tek seferlik satın alma yap (~27 €). Java + Bedrock paketi aynı satın almayla gelir. Aboneliksizdir.

Crack / korsan hesap çalışır mı?

Hayır. Marsana yalnızca resmi Microsoft kimlik doğrulamasını kullanır. Cracked hesaplar desteklenmez ve oyun sunuculara bağlanamaz.

Mod nasıl eklerim?

Mod paneli'nden bir yükleyici seç (Fabric, Forge vb.). Hazır seçenekler (Shader+FPS, OptiFine, Kabartmalı bloklar) otomatik kurulur. Kendi mod dosyalarını eklemek için mods/ klasörüne .jar bırakman yeterli — bu klasörü ayarlarda "Oyun Klasörünü Aç" ile bulabilirsin.

Oyun açılmıyor, ne yapayım?

Sağ panelde "Log'lar" sekmesinden Minecraft çıktısını görebilirsin. Sık karşılaşılan nedenler: yetersiz RAM (kaydırıcıyı yükselt), uyumsuz Java sürümü (Marsana otomatik yönetir ama JAVA_HOME tanımlıysa çakışabilir), bozuk mod jar'ı. Hala çözemezsen GitHub Issues sayfasında log'larla birlikte sorun aç.

macOS “zarar verebilecek yazılım” / Gatekeeper uyarısı veriyor

Bu bir virüs uyarısı değildir. Marsana Launcher henüz Apple Developer ile imzalanmadığı için macOS her indirilen uygulamada bu mesajı gösterir. Kaynak kod GitHub'da açık ve inceleyebilirsin.

Yöntem 1 — Sağ tıkla Aç (en kolay):

  1. Applications (Uygulamalar) klasöründe Marsana Launcher'a sağ tıkla (veya Control+tık).
  2. Aç (Open) seç — normal çift tıklama değil.
  3. Çıkan pencerede tekrar Aç de.

Yöntem 2 — Sistem Ayarları:

  1. Önce uygulamayı normal çift tıkla (engellensin).
  2. Sistem Ayarları → Gizlilik ve Güvenlik aç.
  3. Aşağı kaydır; “Marsana Launcher engellendi” satırında Yine de Aç (Open Anyway) tıkla.

Yöntem 3 — Terminal:

xattr -cr "/Applications/Marsana Launcher.app"

Ardından uygulamayı normal şekilde açabilirsin. İlk başarılı açılıştan sonra uyarı genelde bir daha çıkmaz.

Verilerim nerede saklanır?

Windows: %APPDATA%\marsana-launcher\; macOS: ~/Library/Application Support/marsana-launcher/; Linux: ~/.config/marsana-launcher/. Token, dünyalar ve oyun dosyaları burada tutulur; uygulamayı silmek bu klasörü silmez.

Açık kaynak mı? İnceleyebilir miyim?

Evet, kod tamamen açık. GitHub repo üzerinden inceleyebilir, katkı yapabilir, kendi fork'unu oluşturabilirsin.

Otomatik güncelleniyor mu?

electron-updater entegre; yeni sürüm yayımlandığında uygulama içinden bildirim alır ve tek tıkla güncellersin.

Bu site neden sesli okunabiliyor?

Tarayıcının yerleşik Web Speech API'sini kullanıyoruz; harici bir servis veya hesap gerekmez. Sayfanın sağ üstündeki panelden "Sesli Dinle"ye basıp ses ve hız seçebilirsin. Türkçe sesin yüklü değilse sistemin varsayılan sesi devreye girer.
